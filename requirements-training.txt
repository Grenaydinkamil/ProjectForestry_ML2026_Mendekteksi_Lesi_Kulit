# Python 3.13.9  -> venv utama di Windows (TRAINING + APP)
# TensorFlow 2.21.0 (Keras 3.15.1) -> wheel win_amd64 CPU-only

#   Kenapa CPU-only di Windows?
#     Dokumentasi resmi TensorFlow menyatakan TensorFlow 2.10 adalah
#     rilis TERAKHIR yang mendukung GPU di Windows native. Mulai 2.11,
#     GPU di Windows hanya bisa lewat:
#       (a) WSL2  -> pip install "tensorflow[and-cuda]"
#       (b) Colab -> training di cloud
#     (dokumentasi: tensorflow.org/install/pip, bagian "Windows Native")
#
#   Strategi proyek ini:
#     - Training model klasik (SVM/RF)  : CPU Windows, cepat
#     - Training CNN + MobileNetV2      : WSL2 + GPU (RTX 5070)
#     - Inference aplikasi Streamlit    : tensorflow-cpu (ringan, portable)
#
#   WSL2 setup (sudah dilakukan di mesin ini):
#     wsl -d Ubuntu-26.04 -u root -- bash <skrip-setup>
#     -> Python 3.12 + TensorFlow 2.21 dengan CUDA, GPU terdeteksi
